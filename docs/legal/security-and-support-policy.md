# セキュリティ更新・サポート方針（販売開始前ドラフト）

## サポート期間

初期条件案は購入日から12か月です。対象バージョンと期間は購入記録および購入完了メールで確認できるようにします。期間後も購入済みアプリは継続利用できますが、更新・問い合わせ対応を保証しません。

## 脆弱性の報告と修正

アプリ本体または同梱コンポーネントに影響する脆弱性を確認した場合、NIHO株式会社は影響、回避策、修正版の提供時期を調査します。サポート期間中、サポート対象製品の修正版を追加料金なしで提供します。修正の所要時間や、第三者ライブラリ側の対応時期は保証しません。

- 報告窓口: [セキュリティ専用メールアドレスを用意]
- 公開告知: [販売サイトの更新履歴またはSecurityページ]
- 連絡時に含める内容: 影響する製品・バージョン、再現手順、影響の説明。実データや個人情報は送らないでください。

修正版を用意したら、対象バージョン、修正内容、入手先を告知します。脆弱性の詳細は、購入者が更新を適用できるまで公開を調整する場合があります。

## 更新方法

1. 販売サイトから最新のZIPをダウンロードする。
2. PDF editorを終了する。
3. 新しいアプリを展開して、既存のアプリと置き換える。
4. アプリを起動して、バージョン表示を確認する。

アプリからの自動更新、ライセンス認証サーバーへの定期接続、利用状況の送信は行いません。更新配布時は、バージョンとSHA-256チェックサムを表示する運用を推奨します。

## サポート範囲

サポート期間中、基本操作、インストール、再現可能な不具合の問い合わせに対応します。PDFの修復、第三者ソフトとの競合、データ復旧、個別環境の調査、即時応答はサポート範囲外です。回答は合理的な範囲で行い、SLAは設けません。
