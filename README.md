# PDF editor

Mac上でPDFを開き、既存テキストの置換、任意位置への新しいテキスト追加、複数PDFの結合、ページサイズ変更、印刷ができる個人用デスクトップアプリです。

## ソースの置き場所

ソースはこの `pdf-editor` リポジトリで管理します。リポジトリをcloneしたディレクトリで以下のコマンドを実行します。

専用アイコンは、帳票の既存文字を選択して編集する操作を、紙・選択範囲・入力カーソルで表現しています。

## 起動

デスクトップの `PDF editor` アイコンをダブルクリックすると、ファイル選択画面からPDFを開けます。

ビルド済みアプリは `dist/PDF editor.app` にあります。必要ならデスクトップへコピーできます。

PDFを指定して直接開きたい場合は、Terminalで次を実行します。

```bash
./open-pdf.command "/path/to/請求書.pdf"
```

PDFを指定せず起動して、GUIから選ぶこともできます。

```bash
./open-pdf.command
```

初回だけSwiftのrelease buildに少し時間がかかり、`dist/PDF editor.app` が作られます。2回目以降はそのMacアプリを直接起動します。

## 使い方

1. PDFを開く。
2. 変更したい既存文字をクリックする。複数の文字や括弧をまとめて選ぶときは、先頭から末尾までドラッグする。選択した文字列はPDF上でドラッグして移動できる。
3. 置換する場合は選択文字をダブルクリックしてPDF上で直接編集し、`Return` で確定する。`Escape` で編集を取り消す。表示から消す場合は「選択文字を表示から削除」を押す。
4. 「書き出す」または `⌘S` で、`-edited.pdf` として別名保存する。

未埋め込みフォントの置換では、同じ行に続く文字を右へ移して置換後の幅を作ります。PDFのフォント名に一致するローカルフォントがない場合は、同梱のNoto Sans JPを使います。このMacにMicrosoft Wordがあれば、Word内の `msgothic.ttc` をこのアプリの実行中だけ登録し、MS ゴシックを置換とテキスト追加に使えます。フォント本体はアプリへコピーしません。Wordにない別の `.ttf` / `.otf` / `.ttc` は右側の「フォントファイルを読み込む」から登録できます。Noto Sans JPのライセンスは `Resources/ThirdParty/NotoSansJP-OFL.txt` に収録しています。

PDF表示上部のコントロールで拡大・縮小、倍率の直接入力、ページ全体・ページ幅・実寸表示を切り替えられます。`+` / `-` / `0` キー、CommandまたはControlキーを押しながらのマウスホイール／スクロール、トラックパッドのピンチ操作でも倍率を変えられます。虫眼鏡を使うとポインター付近を一時的に拡大でき、`Esc`で閉じられます。表示倍率の変更はPDFの内容や編集座標を変更しません。

任意位置へ追加する場合は「テキストを追加」へ切り替え、PDF上をクリックして入力します。周囲の文字からフォント・サイズ・色を自動推定し、必要なら右側でフォント、6〜72ptのサイズ、色を変更できます。Returnで確定した後も、追加文字をPDF上でドラッグして移動できます。

`⌘Z` または「直前の変更を取り消す」で、直前の置換・削除・追加を取り消せます。

### PDFを結合する

メニュー、上部の「結合」、または開始画面の「複数のPDFを結合」から結合画面を開きます。PDFを追加すると各ファイルの先頭ページがサムネイルで表示されます。サムネイルを移動先へドラッグ＆ドロップすると順番が変わります。矢印ボタンでも移動できます。番号・ファイル名・ページ数を確認して「結合して保存…」を押すと、左から右、上から下の順で各PDFの全ページを結合します。元のPDFは変更しません。コピーやページ組み替えが許可されていないPDF、ロックされたPDFは結合できません。

### 印刷する

編集するPDFを開いた状態で、上部の「印刷」または `⌘P` を押すとmacOS標準の印刷ダイアログが開きます。確定済みの置換・削除・追加は印刷用の一時PDFへ反映されます。未確定の入力がある場合は、確定するか破棄するかを選んでから印刷します。印刷が許可されていないPDFは印刷できません。

### ページサイズを変更する

PDFを開き、上部の「ページサイズ」またはファイルメニューの「ページサイズを変更…」を選びます。A4・A5・JIS B4・JIS B5・JIS B6、または幅と高さをmmで指定できます。「別名で保存…」から変換後のPDFを保存します。元PDFは上書きしません。

元ページの縦横比を保って指定サイズに収めます。比率が違う場合は余白が入り、画像の画素数は増えません。B5仕上がりの中綴じ冊子なら、印刷時はB4用紙と小冊子印刷を選びます。PDFのページサイズ変更だけでは小冊子用の面付けは行いません。

変換には同梱の [pdfcpu](https://github.com/pdfcpu/pdfcpu) v0.16.2 を使用します。アプリのビルドにはGo 1.26以降が必要ですが、ビルド済みアプリの利用時にはGoのインストールは不要です。Go依存ライブラリのライセンスとNOTICEは `Resources/ThirdParty/THIRD-PARTY-NOTICES.txt` に収録しています。

### PDFを圧縮する

PDFを開き、上部またはファイルメニューの「PDFを圧縮…」を選びます。初期値は印刷向けの弱圧縮98%、ほかに標準95%、強圧縮90%と中間値を選べます。写真の画質を一切変えたくない場合は「画像を再圧縮しない（可逆）」を選びます。この場合は画像データを維持するため、容量はほとんど減らないことがあります。「サイズを試算」を押すと実際に一時PDFを作り、圧縮後のMB、元ファイルからの削減率、正確なバイト数を表示します。「別名で保存…」は試算したPDFをそのまま保存します。元PDFは上書きしません。確定済みのテキスト編集は圧縮前に反映され、未確定の入力がある場合は確定するまで試算できません。

画質の%は**目標ファイルサイズの%ではありません**。画質を上げると画像の劣化は少なくなりますが、削減量も小さくなる傾向があります。対応する8ビットRGB画像だけをJPEGへ変換し、変換後の画像データが小さくなる場合に採用します。画像の画素数、ページ数、ページの寸法を変えず、文字・タグ構造・注釈を可能な限り保持します。共有や変形された画像の使い方を壊さないため、この段階ではページ外の画像領域の切り落としは行いません。

## 現在のMVPの範囲

- 文字レイヤーを持つPDFが対象です。スキャン画像だけのPDFにはOCRが必要です。
- 任意位置への追加は横書き1行に対応します。回転・縦書き・複数行は未対応です。
- 編集中のプレビューでは、元文字を白で覆い、同じ位置へPDF注釈として新しい文字を重ねます。白背景の帳票向けです。
- 書き出し時は置換・追加文字をCoreTextでPDFへ描画します。PDF上でテキストとして抽出でき、開き直したPDFでも選択できます。
- 元PDFは上書きせず、編集済みPDFを別ファイルへ保存します。
- 置換では、同一行の後続文字（別フォントrunに分かれた文字を含む）を移動して置換文字列の幅を確保します。空き幅が足りない場合は文字の縦横比を保って縮小します。
- 日本語ゴシックの既定代替として、SIL Open Font License 1.1のNoto Sans JPを同梱します。MS GothicはMicrosoft Wordにあるローカルの `msgothic.ttc` をプロセス内だけで登録します。使用できるフォントファイルは「フォントファイルを読み込む」から実行中のアプリへ登録できます。
- 置換・表示からの削除は、元の文字を白で覆う方式です。content stream からは消しません。書き出したPDFに対して `pdftotext` 等でテキスト抽出すると、白で隠した元の文字列が依然として取得できます。完全に消去するには content stream の書き換えが必要です。機密情報の抹消には使用しないでください。
- PDF結合はページをPDFKitでコピーするため、ページサイズ、回転、文字、既存注釈を保持します。しおりなど文書全体の構造は引き継ぎません。

```bash
swift build
swift test
./scripts/build-app.sh
PDFCPU_PATH="$PWD/dist/PDF editor.app/Contents/Helpers/pdfcpu" swift test --filter PDFPageResizeEngineTests
```
